Yo'l xaritasi / 4. Ma'lumotlar bazasi

Ma'lumotlar bazasi: Oracle va PL/SQL

Bank hisoblari, o'tkazmalar va provodkalar oxir-oqibat bazada yashaydi. Bu yo'nalish bazani eng boshidan ochadi: nega fayl yetmay qolgan, relyatsion g'oya qanday tug'ilgan, SQL ichkarida qanday bajariladi, Oracle xotira va diskda qanday tuzilgan, tranzaksiya va qulflar pulni qanday himoya qiladi, va PL/SQL qayerdan kelgan.

Bu yo'nalish Java'dan oldinga olingan: Oracle PL/SQL developer vakansiyalariga tayyorlanish uchun. Poydevor yo'nalishidagi P0 darslari (ayniqsa 5-dars: RAM va disk) shu yerda tayanch bo'ladi.

D0. Fayldan bazagacha

  1. Ma'lumotni faylda saqlash va og'riqlaritayyor
  2. Ierarxik va tarmoq bazalari, Codd va relyatsion g'oyatayyor
  3. Oracle tarixi: v2 dan 26ai gachatayyor

D0 xulosa va testtayyor

D1. Relyatsion model va SQL

  1. Jadval, kalitlar, bog'lanishlar, normallashtirishnavbatda
  2. SELECT qanday bajariladi: tartib, WHERE, GROUP BY, HAVINGnavbatda
  3. JOIN turlari ichkaridannavbatda
  4. Subquery, CTE (WITH), CONNECT BYnavbatda
  5. Analitik (window) funksiyalarnavbatda
  6. NULL, tiplar, sana va pul (NUMBER)navbatda

D1 xulosa va test

D2. Oracle ichkaridan

  1. Instance va baza: SGA, PGA, jarayonlarnavbatda
  2. Disk: blok, segment, tablespace, redo va undonavbatda
  3. So'rov yo'li: parse, bind, execute, fetchnavbatda

D2 xulosa va test

D3. Tranzaksiyalar

  1. ACID, COMMIT, ROLLBACK, SAVEPOINTnavbatda
  2. MVCC va izolyatsiya darajalarinavbatda
  3. Qulflar, lost update, deadlock, SELECT FOR UPDATEnavbatda

D3 xulosa va test

D4. Tezlik

  1. B-tree va boshqa indekslarnavbatda
  2. Optimizator va EXPLAIN PLANnavbatda
  3. JOIN usullari, statistika, partitsiyalashnavbatda

D4 xulosa va test

D5. PL/SQL

  1. PL/SQL nega paydo bo'lgan: blok, o'zgaruvchilar, tiplarnavbatda
  2. Kursorlarnavbatda
  3. Exception va loglashnavbatda
  4. Protsedura, funksiya, paketnavbatda
  5. Kolleksiyalar, BULK COLLECT, FORALLnavbatda
  6. Dinamik SQL va SQL injectionnavbatda
  7. Trigger, avtonom tranzaksiya, DBMS_SCHEDULERnavbatda

D5 xulosa va test

D6. Java'dan bazaga (keyinroq)

  1. JDBC, connection pool, Hibernatenavbatda
