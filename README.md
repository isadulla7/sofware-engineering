# Software engineering: pastdan tepaga

Backend muhandisligi bo'yicha o'zbek tilidagi o'quv kursi. Har bir texnologiya o'z ildizidan bugungi holatigacha ochiladi: qanday og'riqdan tug'ilgan, ichkarida qanday ishlaydi, qanday o'zgargan va amalda qanday qo'llanadi.

Sayt sifatida ochish: repo sozlamalarida GitHub Pages yoqilgach, `https://isadulla7.github.io/sofware-engineering/`.

## Yo'nalishlar

1. Poydevor: kompyuter ichkaridan
2. Java
3. Algoritmlar va ma'lumot tuzilmalari
4. Ma'lumotlar bazasi: Oracle va PL/SQL
5. Tarmoq
6. Spring
7. Infratuzilma
8. Xabar almashish
9. Katta loyiha

O'qish tartibi: Poydevordan keyin 4-yo'nalish (Oracle va PL/SQL) Java'dan oldinga olingan. Papkasi: `4-baza/`.

## Tuzilishi

```
index.html            yo'l xaritasi: barcha yo'nalishlar, darslar va holati
assets/style.css      umumiy ko'rinish
assets/evo.js         texnologiya bosqichlari ko'rsatkichi
1-poydevor/           har bir yo'nalish o'z papkasida, har bir dars alohida fayl
android-suhbat/       Android suhbati uchun tezlashtirilgan bo'lim
plsql-suhbat/         Oracle PL/SQL suhbati uchun tezlashtirilgan bo'lim
arxiv/                yangi formatga o'tishdan oldingi sahifalar
```

Sayt oddiy HTML, yig'ish bosqichi yo'q: faylni brauzerda ochsangiz ishlaydi.

## Har bir dars

Qamrov, og'riq, ichkarida ishlashi (arxitektura chizmasi), yaratilishi va o'zgarishi, atamalar, amaliyotda, mashq, tekshiruv, chuqurroq.
